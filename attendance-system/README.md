# 🏫 ระบบเช็กชื่อนักเรียน

Web Application สำหรับครูผู้สอน ใช้เช็กชื่อนักเรียนรายวันตลอดภาคเรียน

## 🚀 วิธีติดตั้งและใช้งาน

### ความต้องการ
- Node.js v16 ขึ้นไป
- npm

### ติดตั้ง
```bash
npm install
```

### เริ่มใช้งาน
```bash
npm start
```
เปิดเบราว์เซอร์ไปที่ **http://localhost:3000**

---

## 📋 ฟีเจอร์

| หน้า | คำอธิบาย |
|------|----------|
| 📊 Dashboard | ภาพรวมสถิติการเข้าเรียน กราฟ 7 วันล่าสุด |
| ✅ เช็กชื่อ | เช็กชื่อรายวัน เลือกสถานะ มา/ขาด/ลา บันทึกหมายเหตุ |
| 📋 รายงาน | รายงานรายวัน + สรุปทั้งเทอม ค้นหาย้อนหลังได้ |
| 👨‍🎓 จัดการนักเรียน | เพิ่ม แก้ไข ลบ อัปโหลดรูปภาพ |
| 📷 QR Code | สร้าง QR ต่อนักเรียน + สแกนเช็กชื่ออัตโนมัติ |

## 🎨 สีสถานะ
- 🟢 **มาเรียน** = สีเขียว
- 🔴 **ขาดเรียน** = สีแดง  
- 🟡 **ลา** = สีเหลือง

## 🗄️ ฐานข้อมูล
ใช้ SQLite (sql.js) เก็บไว้ที่ `data/attendance.db`
